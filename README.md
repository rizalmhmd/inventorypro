## 📋 Tentang InventoryPro

**InventoryPro** adalah sistem manajemen inventori modern yang dibangun dengan Laravel, menawarkan antarmuka yang intuitif dan fitur lengkap untuk mengelola stok produk, transaksi, dan laporan bisnis Anda.

### ✨ Fitur Utama

- 🚀 **Dashboard Real-time** - Pantau stok dan aktivitas secara live
- 📦 **Manajemen Produk** - Kelola produk dengan SKU, kategori, dan deskripsi
- 📊 **Sistem Stok** - Keluar/masuk stok dengan tracking lengkap
- 👥 **Multi-user** - Role-based access (Admin & Staff)
- 📱 **Responsive Design** - Optimal di desktop dan mobile
- 🏷️ **QR Code Generator** - Label produk dengan QR code
- 📈 **Laporan Detail** - Laporan transaksi dan stok
- 🎨 **Modern UI** - Glassmorphism design dengan dark theme

## 🛠️ Teknologi yang Digunakan

- **Backend**: Laravel 10.x
- **Frontend**: HTML, CSS, JavaScript
- **Database**: MySQL
- **Styling**: Custom CSS dengan Glassmorphism Design
- **Icons**: Font Awesome
- **QR Code**: QRCode.js
